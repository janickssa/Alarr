# Quorum web

SvelteKit single-page app (TypeScript, `adapter-static`). The production build in `build/` is embedded into `quorum-server`.

See the [project README](../README.md) for scope and phases.

```sh
npm ci
npm run dev      # dev server
npm run lint     # prettier + eslint
npm run check    # svelte-check / TypeScript
npm run build    # static build into build/
```
